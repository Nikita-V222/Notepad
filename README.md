# Java Notepad App

This is a simple Java GUI-based Notepad application built using Swing.

## 🚀 Run the App

### 🔗 [Click here to download the JAR](https://github.com/Nikita-V222/Notepad/raw/main/NotepadApp.jar)

Once you've downloaded the `NotepadApp.jar`, follow the instructions below to run the app:

### 💻 To run it (requires Java installed):
1. Open a terminal or command prompt.
2. Navigate to the folder where you saved `NotepadApp.jar`.
3. Run the following command:
   ```bash
   java -jar NotepadApp.jar


### 🧠 Features
-Create, edit, and save text files.
-Simple Swing-based user interface.
-Lightweight and beginner-friendly.
